# Original portfolio snapshot

These are the original HTML, styles, scripts, and media, including the local edits
to `augmum.html` and `chefu.html` present before the rebuild. They are retained as
the content baseline and are **not included in the deployed site**.
Sidewalk Robot's gallery images and video demo have been removed from this archive
as well as from the active site's assets at the user's request.

The active application is in `src/`; deployable static assets are in `public/`.
`scripts/verify-content.py` compares generated pages against the current editable
portfolio data; this archive is retained only as the original migration reference.
The one-time migration utility can reproduce `src/data/portfolio.json` from these
original pages; do not rerun it after intentionally updating the new content.
